# Успішність студентів

Вебзастосунок для обліку академічної успішності: студенти, групи, предмети, семестри,
оцінки та відомості з автоматичним розрахунком середнього балу й статистики по групах.

## Можливості

| Роль | Що може |
|---|---|
| **Адміністратор** | керує користувачами та ролями, довідниками (групи, предмети, семестри), переглядає заявки на предмети |
| **Викладач** | створює курси й групи, запрошує колег, виставляє та редагує оцінки, формує відомості |
| **Студент** | бачить власний профіль, оцінки та розраховану успішність за семестрами |

Спільне для всіх ролей: авторизація, захищені маршрути за роллю, валідація форм,
окремі сторінки помилок 403/404/500.

## Демо

Застосунок розгорнуто й доступний для перевірки:

> **Посилання на робочий вебзастосунок: `<буде додано>`**

Доступ до розділів розмежований ролями. Тестові облікові записи:

| Роль | Логін | Пароль | Що доступно після входу |
|---|---|---|---|
| Адміністратор | `admin` | `admin123` | керування користувачами, довідниками, семестрами, заявками |
| Викладач | `teacher` | `teacher123` | курси, групи, запрошення, виставлення оцінок |
| Викладач | `teacher_vdovychyn` | `teacher123` | курси другого викладача (перевірка розмежування) |
| Студент | `visitor` | `visitor123` | власний профіль і своя успішність |

## Стек

| Шар | Технології |
|---|---|
| Runtime | Node.js, ESM (`type: module`) |
| HTTP | Express 5 |
| Шаблони | Nunjucks |
| База даних | Sequelize (SQLite або PostgreSQL) |
| Авторизація | Passport (local strategy), bcryptjs |
| Сесії | express-session |
| Конфіг | dotenv |

## Структура

```
src/
├── app.js              точка входу
├── api/index.js        serverless-адаптер для хостингу
├── config/             підключення до БД, passport, сіди, опис таблиць
├── controllers/        обробники маршрутів (auth, student, teacher, semester, admin, api)
├── middleware/         перевірки доступу та валідація
├── models/             моделі Sequelize
├── routes/             маршрутизація
├── services/           бізнес-логіка (розрахунок успішності, зв'язки)
├── utils/              допоміжні функції
├── views/              шаблони Nunjucks
└── public/             статика (css, js)
```

## Запуск локально

```bash
npm install
cp .env.example .env      # за потреби заповнити DB_*
npm run dev               # або npm start
```

За замовчуванням використовується SQLite: файл `app.db` створюється автоматично разом
із таблицями й тестовими акаунтами.

## База даних

| Режим | Коли використовується | Налаштування |
|---|---|---|
| **SQLite** | за замовчуванням, зокрема на хостингу | нічого не потрібно, схема створюється з моделей |
| **PostgreSQL** | локально з повноцінною БД | `DB_DIALECT=postgres` + `DB_*` змінні, схема з `sql.sql` |

Приклад для PostgreSQL:

```bash
psql -U postgres -f ../sql.sql
```

## Змінні середовища

| Змінна | Призначення |
|---|---|
| `PORT` | порт HTTP-сервера |
| `DB_DIALECT` | `sqlite` (типово) або `postgres` |
| `DB_STORAGE` | шлях до файлу SQLite |
| `DB_NAME` | назва бази PostgreSQL |
| `DB_USER` / `DB_PASSWORD` | користувач і пароль PostgreSQL |
| `DB_HOST` / `DB_PORT` | адреса і порт PostgreSQL |
| `SESSION_SECRET` | секрет для підпису сесій |

## Безпека

- Паролі зберігаються лише як bcrypt-хеші.
- Секрети — тільки в `.env`, який виключений через `.gitignore`.
- Сесійні cookie: `httpOnly`, `sameSite`.
- Доступ до розділів перевіряється middleware за роллю, а не приховуванням посилань.
